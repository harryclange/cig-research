How It Works

A deeper look at the strategies that make CIG outputs consistent and accurate at scale.

Style Reference Enforcement

The central challenge in catalog photography isn't generating a single good image—it's generating thousands of images that look like they belong together. CIG achieves this computationally through a style reference library—a curated set of "gold standard" product photos that define the target aesthetic: background, lighting, framing, and shadow behavior.

The model extracts only environmental properties from references while ignoring the garments within them. Without this decoupling, the model tends to "borrow" design elements from reference garments, contaminating the output.

Reference Isolation Protocol

Source images are "bookended"—placed at both the beginning and end of the input sequence—creating an anchoring effect that prevents reference contamination:

[Source] [Ref 1] [Ref 2] ... [Ref N] [Source]

This reduced reference contamination from ~35% to <5%.

Multi-View Construction Inference

Ghost mannequin rendering requires understanding garment construction that may not be visible from a single angle. A halter dress with a tie-back closure will be incorrectly rendered with a clasp if the model only sees the front.

CIG accepts multi-view inputs (front + back). The model uses the alternate view as a construction reference, enabling accurate reproduction of closures, seam lines, and structural details. Both front and back renders are produced, using each as the other's reference.

Two-Pass Critique Loop

Rather than accepting single-shot output, CIG employs an automated critique-and-correct loop with two independent checks:

Garment Fidelity

Compares output against source: color, structural integrity, detail preservation, state consistency. Only flags customer-visible issues.

Style Consistency

Compares output against the style library: background purity, lighting match, framing, shadow behavior. Ensures catalog coherence.

Failed critiques produce specific correction instructions that are injected into subsequent generation passes (up to 3 attempts), raising output quality from ~80% first-pass to >95%.

Flat-Lay Cleanup

Source images often arrive as informal flat-lays with uneven folds and casual arrangement. CIG's cleanup mode re-styles the arrangement (straighten, center, symmetrize) without altering the garment itself—no color, pattern, detail, or state changes permitted. This boundary is enforced through constraint separation and validated by the fidelity critique.

Drape Intelligence

A tunable parameter (0.0–1.0) controls the model's understanding of fabric behavior, from ultra-fluid silk to rigid denim:

Ultra-fluid (silk, satin)

0.2 – 0.4

Soft gentle creases, natural fall
0.4 – 0.6

0.6 – 0.8

0.8 – 1.0

Minimal draping, firm structure

Accuracy Reinforcement

Image generation models naturally "idealize" their subjects. For product photography this is a failure mode—garments must look exactly as they'll arrive. CIG enforces fidelity through a tunable preservation parameter:

High Fidelity (0.8–1.0)

Pixel-level preservation. Every stitch, button, logo, seam, and texture must match. Used for production renders.

Balanced (0.5–0.8)

Key elements preserved but minor re-draping permitted. Useful for low-quality source photos.
